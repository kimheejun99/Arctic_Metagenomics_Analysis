전체 파이프라인 파일 구성 안내 (2개 오케스트레이터 구조)
=====================================================================

이 zip 안의 모든 파일을 서버의 "같은 폴더"에 그대로 풀어서 사용하세요.
(하위폴더로 나누지 마세요 - 모든 스크립트가 flat 구조를 기대합니다)

┌─────────────────────────────────────────────────────────────┐
│ Pipeline 1: run_pipeline.sh  (자료 생성)                      │
│   V1(다운로드) → V5(Kraken2) → V2(fastq→fasta) → V3(Diamond) │
│   → A2(ARGs-OAP) → V6(eggNOG-mapper, 신규) → V4(VF 파싱)     │
│   → V9(정리) → result/로 자동 이동 → (있으면) Pipeline 2로 자동 이어짐│
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼ (result/ 폴더가 다음 단계의 작업 위치)
┌─────────────────────────────────────────────────────────────┐
│ Pipeline 2: run_pipeline_analysis.sh  (분석)                  │
│   Step1~4  VF/ARG/Taxonomy 취합                               │
│   Step5    eggNOG 결과 정리 + KEGGaNOG 완성도 분석             │
│   Step6    통계적 검증(ANCOM-BC2 3종)                          │
│   Step7    Host-tracing                                       │
│   Step8    심화 taxon 귀속 검증                                │
│   Step9    시퀀싱 깊이 교란요인 검증                            │
│   Step10   Genus 수준 최종 통계 검증                            │
└─────────────────────────────────────────────────────────────┘

실행 순서:
  1) conda activate ArcticVF (Pipeline 1용: kraken2, diamond, seqkit, args_oap 등)
     bash run_pipeline.sh biosample_sra_matches.txt
     -> 끝나면 result/ 안에 run_pipeline_analysis.sh를 자동 복사해 이어서 실행 시도
       (자동 연결 안 되면 아래 2번을 수동으로)

  2) cd result
     conda activate ArcticAnalysis (Pipeline 2 Step1~4용: pandas, matplotlib)
     bash run_pipeline_analysis.sh sample_coords.txt sample_list.txt metadata.txt
     -> conda 환경은 신경 안 쓰셔도 됩니다. Step5 이후 필요한 eggnog/r_ancombc
        환경은 스크립트가 내부에서 알아서 전환합니다(run_in_env 헬퍼).

  3) 특정 Step만 재실행하고 싶으면 4번째 인자로 지정 (범위도 가능):
     bash run_pipeline_analysis.sh sample_coords.txt sample_list.txt metadata.txt 7
     bash run_pipeline_analysis.sh sample_coords.txt sample_list.txt metadata.txt 5-10

필요한 conda 환경 3개:
  ArcticVF       : Pipeline 1 (kraken2, diamond, seqkit, args_oap, sra-tools)
  ArcticAnalysis : Pipeline 2 Step1~4 (python 3.10, pandas, matplotlib)
  eggnog         : Pipeline 1의 V6, Pipeline 2 Step5~9 (eggNOG-mapper, KEGGaNOG, seaborn)
  r_ancombc      : Pipeline 2 Step6, 10 (R, bioconductor-ancombc, phyloseq)

참고 - 파이프라인에 포함되지 않는 수동 단계:
  SimpleMicrobiome 웹사이트를 이용한 Phylum/Genus 시각화는 외부 웹 도구라
  스크립트로 자동화되지 않습니다. Pipeline 2 Step4가 만드는
  merged_tables/2_taxonomy_table.txt(또는 원본 .kreport)를 그 웹사이트에
  직접 업로드하시면 됩니다.

자세한 내용은 README.md 참고.
